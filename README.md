## ⚡ Fitur & Standar Pengembangan

Proyek ini dikembangkan dengan standar ketat:
* **Anti-Slop UI**: Desain autentik dengan tipografi berkarakter, kontras tegas, dan micro-interaction bermakna (menghindari template AI generik).
* **Code Hygiene**: Bersih dari kode redundan (*dead code*), ringan, dan token-optimized.
* **Production Security**: Sanitasi input, proteksi kebocoran kredensial/rahasia, serta pencegahan kerentanan web modern (OWASP).
* **Accessible & Responsive**: Optimal di semua ukuran layar dan ramah aksesibilitas.
